# TaskFlow API

**Status: Planned**

A production-style task management REST API designed to demonstrate backend fundamentals.

Planned scope:
- FastAPI endpoints for users, projects, and tasks
- PostgreSQL persistence with SQLAlchemy
- Pydantic request and response validation
- Authentication and role-based access
- Filtering, sorting, and pagination
- Unit and API tests with pytest
- Docker Compose for local development

The project will use fictional data and be implemented independently.
